## Featured Open-Source Projects

- [NativeBase](https://github.com/GeekyAnts/NativeBase): A component library that helped developers build consistent experiences across React Native applications.
- [gluestack-ui](https://github.com/gluestack/gluestack-ui): Customizable React Native and Expo components and patterns built with Tailwind CSS and NativeWind.
- [GeekLego](https://github.com/GeekyAnts/geeklego): An open-source, design-system-first React component library built with Tailwind CSS and Radix UI.
- [Vue Native](https://github.com/GeekyAnts/vue-native-core): A framework for building cross-platform native mobile applications with Vue.js and React Native.
- [SyncState](https://github.com/syncstate/core): Document-based state management for real-time, multi-user, offline-first, and undoable JavaScript applications.
- [React Pluggable](https://github.com/GeekyAnts/react-pluggable): A plugin system for organizing React applications around features instead of tightly coupled components.
- [Flutter Starter](https://github.com/GeekyAnts/flutter-starter): A practical foundation for Flutter applications with common modules for state management, APIs, and styling.

More at [geekyants.com/open-source](https://geekyants.com/open-source?utm_source=github&utm_medium=referral).
